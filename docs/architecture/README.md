# Architecture Documentation

This directory is the home for SkillMatch's architecture documentation
(domain boundaries, data model rationale, authorization rules, and
sequencing decisions).

The full architecture blueprint that this codebase was scaffolded from is
maintained as a separate design document outside this repository. This
folder is where architecture docs derived from or superseding that
document should be added as the project evolves — it intentionally does
not duplicate the blueprint in code comments.
